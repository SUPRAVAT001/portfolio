The Engineering Problem

Traditional CI pipelines frequently execute direct imperative commands (such as kubectl set image or helm upgrade) into production Kubernetes clusters. This approach forces CI runners to hold high-privilege cluster tokens, and manual cluster modifications go undetected.

This project implements strict GitOps separation: GitLab handles CI, linting, unit testing, and container image publishing, while Argo CD inside the cluster continuously reconciles Kubernetes workloads strictly from the declared Git repository.

5-Stage Hosted GitLab SaaS Pipeline (#3045047835)

  • validate (lint-and-validate · 33.0s): Python py_compile bytecode verification, YAML syntax schema validation, and Helm chart linting (helm lint helm/gitops-demo).
  • test (unit-tests · 25.7s): Runs 6 automated Pytest tests validating application API endpoints, latency, and health handlers, exporting junit-report.xml.
  • build (build-image · 60.2s): Unprivileged multi-stage container build via docker:27-dind over mutual TLS, embedding immutable git commit SHA (9dbdf50d).
  • publish (publish-image · 46.6s): Publishes immutable registry.gitlab.com/supravatdash7399/git-argo:9dbdf50d and updating :latest tags in the GitLab Container Registry.
  • update-gitops (promote-gitops · 21.7s): Promotes both image.repository and image.tag in the GitHub GitOps repository values.yaml via masked personal access token, committing a58cf62 with [skip ci] to avoid recursive loops.

Real Pipeline Issues Diagnosed & Fixed

  • YAML Colon-Parser Collision (commit 1fda3f5): Unquoted echo "==> ...: ${TAG}" lines in .gitlab-ci.yml triggered YAML dictionary key syntax parser collisions. Resolved by single-quoting entire multiline script strings containing colons.
  • alpine/git Entrypoint Collision (commit 9dbdf50): The base alpine/git:2.45.2 container sets ENTRYPOINT ["/usr/bin/git"], causing GitLab's shell runner to fail with git: 'sh' is not a git command. Resolved by overriding entrypoint: [""] in the job definition.
  • Registry Repository Divergence (commit 2376a62): Updating only image.tag left image.repository pointing to DockerHub instead of CI_REGISTRY_IMAGE. Expanded Stage 5 stream editor replacement to synchronize both repository and tag fields atomically.
